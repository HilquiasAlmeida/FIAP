Segurança e Arquitetura de Dados

Diretrizes rigorosas de proteção à privacidade, criptografia e infraestrutura de backend do projeto.

Criptografia de Ponta a Ponta (AES-256)

Para garantir que a localização da criança jamais seja interceptada por terceiros mal-intencionados, todos os pacotes de telemetria gerados pelo hardware em MicroPython são criptografados utilizando o padrão robusto AES-256 (Advanced Encryption Standard) antes de serem enviados ao enlace de satélite.

Arquitetura de Banco de Dados e Servidor

O backend processa as requisições vindas da API da constelação de satélites e armazena os dados em um banco de dados relacional altamente seguro. A arquitetura conta com:

• Isolamento de Credenciais: Acesso restrito e autenticado exclusivamente para os responsáveis legais cadastrados.
• Trilha de Auditoria (Logs): Registro imutável de todas as consultas de rotas e alertas de pânico disparados.
• Conformidade com Privacidade: Retenção controlada de histórico geográfico visando a total proteção dos dados infantis.
