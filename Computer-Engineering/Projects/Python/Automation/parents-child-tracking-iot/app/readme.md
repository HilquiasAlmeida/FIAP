# 📱 App Mobile dos Pais - Rastreamento Infantil IoT

Este diretório contém o código-fonte do aplicativo mobile (desenvolvido em **Flutter**) que os pais instalam em seus smartphones para monitorar a localização em tempo real da criança.

## 🚀 Funcionalidades
- Consulta em tempo real a API do servidor Flask (`/location`).
- Exibição de coordenadas (Latitude e Longitude) e status do dispositivo.
- Botão de redirecionamento direto para o aplicativo nativo do **Google Maps**.

## 🛠️ Tecnologias
- Flutter / Dart
- HTTP Package
- URL Launcher Package
